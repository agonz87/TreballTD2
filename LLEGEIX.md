# Web de client GR20 Nord · Trescamins (Entrega 01)

Web estàtica (HTML, CSS i JavaScript). Conté només la informació comercial per al client:

- `index.html` → portada amb les experiències, el dossier comercial i el contacte
- `gr20.html` → la sortida GR20 Nord: ruta, mapa, preu, el guia, preguntes i reserva
- `reserva.html` → procés de reserva en tres passos
- `docs/Gonzalez_Albert_Entrega_01_Client.pdf` → dossier comercial (PDF)
- `docs/` també conté la fitxa del client i el contracte

## Com publicar-la a GitHub Pages
1. Crea un repositori públic a GitHub.
2. Puja-hi el contingut d'aquesta carpeta (inclòs `.nojekyll`).
3. A *Settings → Pages*, tria *Deploy from a branch*, branca `main` i carpeta `/ (root)`.
4. La web quedarà a `https://EL-TEU-USUARI.github.io/NOM-DEL-REPOSITORI/`.
