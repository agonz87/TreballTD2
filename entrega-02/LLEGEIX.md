# Dossier tècnic del guia · GR20 Nord · Trescamins (Entrega 02)

Web estàtica (HTML, CSS i JavaScript) amb el dossier tècnic per al guia que ha de conduir la travessa Calenzana → Vizzavona (3–11/9/2027):

- `index.html` → dossier: resum, mapa interactiu (plans A, B i C), logística i contactes, protocol d'emergència, normes del Parc, material, perills, criteris de decisió, fitxa de cada etapa (punts clau, horaris, hores límit, plans A/A+/B/C i Pla C amb mapa), plans C d'un cop d'ull, waypoints i transports.
- `gpx/` → 24 arxius GPX: Pla A per dia i ruta completa, Pla B i Pla C per dia (nom `D<dia>_Pla<A|B|C>_<origen-destí>.gpx`) i waypoints.
- `docs/Gonzalez_Albert_Entrega_02_Guia.pdf` → el mateix dossier en PDF.
- `docs/Gonzalez_Albert_Entrega_02_GPX.zip` → tots els GPX en un sol fitxer.

Fonts: OpenStreetMap, EU-DEM, BRouter (trams a peu dels plans B i C), OSRM (taxi). Mapa base: OpenTopoMap.
